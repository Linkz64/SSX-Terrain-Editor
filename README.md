# SSX Terrain Editor
Welcome to SSX Terrain Editor


An editor built in the Godot engine that lets modders edit existing terrain bezier surfaces, or create terrains of their own.

Currently only compatible with ssx tricky. <br>
Works along side the 
[SSX Collection Multitool](https://github.com/GlitcherOG/SSX-Collection-Multitool)


### Features


### Goal
To have a full on terrain editor for SSX (2000), Tricky, 3, and On Tour. 
Easy to interact in-editor tools to facilitate level creation for modder.
